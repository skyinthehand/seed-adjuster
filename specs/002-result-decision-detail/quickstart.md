# Quickstart: 選手別の配置判断根拠の詳細確認

実装後にエンドツーエンドで検証する手順。スキーマの詳細は[contracts/tournament-directory.md](./contracts/tournament-directory.md)、[001/contracts/match-index-format.md](../001-seed-adjuster-webapp/contracts/match-index-format.md)、[001/contracts/api.md](../001-seed-adjuster-webapp/contracts/api.md)を参照。

## 前提

- `indexer/`の依存関係がインストール済み(`pip install .`)であること。
- `frontend/`の依存関係がインストール済み(`npm ci`)であること。
- 001フィーチャーが実装済み・動作していること(結果ページ`/results/:runId`が既に表示できる状態)。

## 1. indexerが`tournamentId`と`tournaments.json`を正しく生成することを確認する

```sh
cd indexer
python -m src.build_index --out-dir dist
```

- `dist/match-index.parquet`に`tournamentId`列が追加されていることを確認する(例: `python -c "import pyarrow.parquet as pq; print(pq.read_schema('dist/match-index.parquet'))"`)。
- `dist/tournaments.json`が生成され、`{"formatVersion": 1, "tournaments": {"<id>": "<name>", ...}}`の形になっていることを確認する。
- ファイルサイズを確認し、research.md R4の見積もり(概ね1MB前後)から大きく外れていないことを確認する。大きく外れる場合はresearch.md R4を見直す。

## 2. 詳細確認UIの基本動作(User Story 1)

```sh
cd frontend
npm run dev
```

1. 既存の完了済みRunの結果ページ(`/results/:runId`)を開く。
2. 調整前後のシード比較表で、任意の選手の行にある詳細確認の操作(ボタン)をクリックする。
3. モーダルが開き、次が表示されることを確認する: 元の順位・比較した対戦相手候補(近い順)・各候補の近さの指標値・採用された判定ロジックの種別・調整後の最終順位。
4. 別の選手の行から詳細確認を開き直し、表示内容が切り替わり前の選手の情報と混在しないことを確認する。
5. 比較対象候補が0件の選手(固定シード等)で詳細確認を開き、「比較対象なし」の旨が表示されエラーにならないことを確認する。

## 3. 大会名・対戦日時の表示(User Story 2)

1. 既知の対戦実績を持つ選手ペアが含まれるRunの結果ページで、詳細確認を開く。
2. 対戦相手候補の一覧で、各候補について実際の大会名・対戦日時が表示されることを確認する。
3. 複数回対戦している候補について、同じ大会・同じ日付の対戦がまとめて1件・対戦回数併記になっていることを確認する(異なる大会・異なる日付は別件のまま)。
4. 実際の対戦記録が1件もない候補について、「対戦履歴なし」等が明示され、近さの指標値など他の情報は通常通り表示されることを確認する。

## 4. 大会名解決の遅延・失敗時の挙動(FR-004, FR-008, SC-004)

1. ブラウザの開発者ツールでネットワークを絞る(Slow 3G等)か、`tournaments.json`へのリクエストをブロックする。
2. 詳細確認を開き、他の情報(元の順位・近さの指標値・対戦日時・採用ロジック・調整後順位)が待たされずに表示されることを確認する。
3. 大会名欄のみ「読み込み中」等の一時表示になり、取得完了後に差し替わる(または失敗時は不明である旨が表示される)ことを確認する。
4. この差し替えの前後で、モーダルの閉じるボタンの画面上の位置が変わらないことを目視で確認する(FR-008)。

## 5. 狭い画面幅での表示(SC-003)

1. ブラウザの開発者ツールでビューポート幅を375px相当に設定する。
2. 詳細確認を開き、レイアウトが崩れず全ての情報が閲覧できることを確認する。

## 6. 既存機能への影響がないことの確認

- 001フィーチャーの既存の結果ページの他の要素(調整前後のシード比較表そのもの、Wave希望を満たせなかった選手の一覧、調整前シード順)が変更前と同じ内容で表示されることを確認する。
- 結果ページが引き続き認証不要でアクセスできることを確認する(FR-007)。
